Halaman ini tayang otomatis

Dari commit di GitHub sampai muncul di VPS sendiri, tanpa upload manual. Persis seperti jalur produksi roti: yang gagal di satu pos tidak akan sampai ke toko.

  1. Commitadonan masuk
  2. Checkoutditimbang
  3. Testdicek bentuknya
  4. Deploydipanggang
  5. Tayangsampai di toko

Yang bekerja di balik halaman ini

GitHub
Sumber kebenaran. Yang tayang harus berasal dari repo, bukan dari edit manual di server.
Jenkins
Menjalankan Checkout, Test, dan Deploy setiap kali ada push.
Nginx
Menyajikan file dari /var/www/html ke browser.

Coba ubah halaman ini

  1. Buka public/index.html di GitHub.
  2. Ganti tulisan Versi 1 menjadi Versi 2, lalu commit.
  3. Buka Jenkins dan lihat build baru muncul.
  4. Refresh halaman ini. Tulisannya sudah berubah.

Kalau tes gagal, tahap Deploy dilewati dan halaman ini tetap tampil versi lama.
